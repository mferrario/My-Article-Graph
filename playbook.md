# Playbook

The current best version of how I work with AI, through two lenses. Each practice is a short imperative statement, followed by a one-line reason and its source notes in [[brackets]]. Arguments and background stay in the notes.

Every section has an ID in backticks. Notes reference these IDs in their `playbook:` frontmatter, which is what makes "what supports or contradicts this section" a search instead of a reread. Rename or add sections freely, but keep IDs stable once notes point at them.
